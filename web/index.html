Welcome to Vue Engine

Build 2D and 3D games with Blocks, Nodes and TypeScript. Every template is a playable game you can take apart.

Templates

Learn the basics

Blocks

Drag event hats like when game starts or every frame, snap actions under them. Great for first games.

Nodes

Wire white execution pins to run steps in order and coloured data pins to feed values. Right-click the canvas to add nodes.

Code

TypeScript with full autocomplete. Export start, update(dt), collide(other) and click. Use vue and self.

2D and 3D

Each scene picks 2D or 3D in the Inspector. Physics, cameras and scripting work the same in both.

Tilemaps

Add a Tilemap, open the Tiles tab and paint with brush, rectangle or fill. Solid tiles collide with dynamic bodies automatically.

Sprite animation

Pick a sprite sheet in the Animation tab, click frames to build a timeline, set the speed, then call self.play("walk") or use the play animation block.

Cutscenes

Stack camera moves, captions, speech, sounds and entity tweens on a timeline. Auto-play on scene start or trigger with vue.cutscene("Intro").

Parenting

Drag an entity onto the middle of another row in the Hierarchy to put it inside. Children move and rotate with their parent.

Audio

Drop WAV, MP3 or OGG files in. Use Audio Source components, sound and music blocks, or vue.play() and vue.music().

Shortcuts

Ctrl+Enter plays, Ctrl+P opens the command palette, Q W E R switch tools, F frames the selection, ? shows every shortcut.

Ship it

Export builds a single HTML file that runs anywhere: itch.io, GitHub Pages, or a friend's browser.
